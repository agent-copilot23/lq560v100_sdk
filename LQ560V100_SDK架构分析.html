镜像产物内容 / 用途
otfl_*.img一级引导 OTFL（DDR/PMIC/TZASC 初始化 + 校验加载），按 spinand/spinor/emmc 分
uboot_*.img · bl31.imgU-Boot 2022.07 + ATF 2.7（secure world），可开安全启动签名
uImage-fdt.gz.imgLinux 5.10.y 内核 + 设备树（内核态媒体驱动以 .ko 形式独立发布）
rootfs_*.ramdisk.imggenromfs 只读根文件系统（BusyBox 1.34.1 + init）
userfs（96M ext4 / 32M ubifs / jffs2）可写用户分区：媒体 .so、模型、加载脚本 load_lq560v100
datafs（~7.8G ext4 / 27M ubifs）数据分区（录像/日志/配置）
emmc_/nand_/nor_upgrade.zip升级包（含 burn_table 分区表），安全启动时附加 .sig 签名
⚠ 关键开关：BOOT_MEDIA(spi/emmc) · BOOT_MODE(normal/ab=A/B双区升级) · SECUREBOOT_TYPE(sm=国密/ecc) · SECUREBOOT_ENC(y/n) · QUICKBOOT_BUILD(y=两阶段快速启动)。工具链固定要求 aarch64-otv02-linux-gnu ver100.140，版本不符会交互提示。

    6｜组件、样例与工具链 main/src/component + opensource + tools

    核心组件（预编译库+头文件+KO）
    • media（438文件）：vi/isp/venc/vdec/vo/ao/vproc/vrb/pipeline/buf_pool/scene_auto/sys，libot_*.a/.so
    • npu：libot_avp_npu（rts/tensor/intf/impl）+ protobuf-c，models：yolov5s、mobilenetv2
    • security：cipher/KM/OTP，样例覆盖 SM2/SM3/SM4/RSA/ECC/TRNG/PBKDF2（国密）
    • smr：Secure Memory Region 内存隔离（内核+用户态）
    • upgrade：ot_bc 启动控制，A/B 双区升级 + minizip 解包
    • safelib：a55_stl（Cortex-A55 安全软件测试库）+ ot_semu（安全机制运行时）
    • oge/gfb：图形/帧缓冲；cve/dpu：视觉/深度处理；board_info：板卡信息；userproc：用户进程框架
    样例程序（开放源码，可直接交叉编译）
    • 采集：sample_vi / sample_mipi / sample_hot_plugin（热插拔）
    • 编码：sample_venc / sample_vdec / sample_vproc
    • 显示：sample_vo / sample_oge；音频：sample_ao
    • AI：sample_ai / sample_media_ai（CVE+NPU 算法库封装）
    • 系统：sample_media_sys / sample_media_pipe / sample_smr / sample_quickboot / scene_auto
    • 升级：sample_upgrade（分区/打包/流程）
    • 安全：sample_cipher/sample_sm2/sample_sm3/sample_sm4…
    工具与开源组件
    • PC 侧工具：image_tool（镜像打包/签名）、boot_tools（regbin：Excel寄存器表→reg_info.bin）、kdf_customer（客户密钥派生）、nand_production、partition_env（分区表）、romfs/genromfs、ubi_sh、misc_tool、compress
    • 板级工具：reg-tools-1.0.0（寄存器读写）、LQ560V100_PQ（画质调试）
    • 开源件：busybox-1.34.1 · openssl-3.2.0 · mtd-utils-2.1.4 · e2fsprogs-1.46.4 · zlib-1.2.12 · xz-5.2.6 · squashfs-4.5 · util-linux-2.37.2 · eudev-3.2.10 · gzip-1.11 · libxml2-2.9.0 · cJSON-1.7.18 · securec（华为安全函数库）
